# Security policy

Report a security issue through
[GitHub private vulnerability reporting](https://github.com/cristianvega-ai/cristianvega.ai/security/advisories/new).
This form sends the report to the repository owner. It requires a GitHub account.
Do not put vulnerability details or credentials in a public issue.

Include the affected URL or file, steps to reproduce the issue, and its effect.
Remove personal data and credentials from examples.

Security fixes apply to the current `main` branch and the deployed site.
Older versions are not maintained.
